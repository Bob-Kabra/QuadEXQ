QuadEXQ 追加システム メモ
================================
対象エンジン: Mark V(host_timescale と エンティティ gravity フィールドを使用。QuakeSpasm系でも動く想定)

新規ファイル
  qx_defs.qc   定数・フィールド・precacheラッパー・プロトタイプ(defs.qcの直後)
  quadexq.qc   本体(progs.srcの最後)

既存ファイルへのフック(すべて "QuadEXQ" コメント付き)
  ai.qc / fight.qc   ai_* 関数の先頭で QX_AIHook()、ai_run で QX_AIRun()
  combat.qc          Killed → QX_OnKilled / T_Damage → QX_DamageMult
  client.qc          PreThink: QX_AirJet / 末尾 QX_PlayerPreBoost
                     PostThink: QX_AutoMelee → W_WeaponFrame → QX_PlayerUnboost → QX_PlayerFrame
                     PutClientInServer末尾 QX_PlayerSpawned
  player.qc          PlayerDie → QX_PlayerDied、player_snail1/2(新SNG)
  world.qc           worldspawn → QX_WorldSpawn、StartFrame → QX_StartFrame、skill を Normal 固定
  weapons.qc         impulse 1/5/150/151、LGにaim()、TraceAttackのaim()撤去、ネイルの威力調整
  frikbot/bot.qc     aim() ラッパーで人間プレイヤーだけモダンエイム
  defs.qc            precache_* 組み込みを *_real に改名(ラッパーはqx_defs.qc)
  各モンスター       亜種判定の cvar("skill") を QX_BASE_SKILL に置換

エンジンHUD(QuadEXQ版 Mark V が必要。普通のエンジンでは表示されないだけで遊べる)
  progs が stat 20〜26 でアドレナリン/PlayerSkill/世界の速さ/ジェット残量/ボス方向を送る
  エンジン側の cvar scr_qxhud 0 で非表示

コンソールコマンド
  impulse 150   ステータス表示(PlayerSkill / 増加率 / 敵倍率 / アドレナリン / 世界の速さ / キル数)
  impulse 151   PlayerSkillを難易度の初期値にリセット

------------------------------------------------------------
PlayerSkill(0〜100)
------------------------------------------------------------
  難易度は PlayerSkill に一元化。メニュー/スタートマップの skill は初期値だけを決める
    初期値 = skill x 20 (Easy 0 / Normal 20 / Hard 40 / Nightmare 60) ※QX_START_PER_SKILL
  EXQ元々の skill 依存処理(亜種の出現率、怯み、ボスなど)は Normal 固定 ※QX_BASE_SKILL
  ※マップ側の「Easyでは出ない/Hardだけ出る」敵の配置だけはエンジンが決めるので難易度で変わる

  増える(基本値): +1 キル / +2 HP300以上の敵 / +5 エリート / +1 生存20秒ごと(実時間)
    実際の増加 = 基本値 x 増加率。増加率 = (100 - PlayerSkill) / 100、最低5% ※QX_SKILL_MINRATE
    → 0→50 キル換算 約70、50→80 約90、80→95 約140、95→100 約100(ほぼ増えない)
  減る: 死亡で -20(常に固定) ※QX_SKILL_DEATH
        敵からの被弾 1ダメージにつき -0.05(100ダメージで -5) ※QX_SKILL_HURT
        自爆・溶岩・落下ダメージは対象外
  ボス撃破: +5(基本値)

  PlayerSkill 50 超え: スーパーネイルガンの追尾が有効
  PlayerSkill 100 到達の瞬間: 生きている敵も含めて全員エリート化(ボス/クトゥン系/smine除く)
    以後に出る敵・リベナントもすべてエリート。死んで100未満に落ちても、そのマップ中の既存エリートはそのまま

  保存先: 値+1 を cvar に保存
    QuadEXQエンジン: qx_playerskill(config.cfg に保存 → 次回起動しても続きから)
    普通のエンジン : temp1(起動中だけ。死亡リスタート・changelevelでは維持)
  初期値に戻るのは: 保存値がまだ無いとき / start.bsp で難易度の床を踏んだとき / impulse 151

  敵への効果(f = PlayerSkill/100、5刻みで反映)
    HP x(1+f)  与ダメ x(1+0.5f)  動作速度 x(1+0.5f)
    回避率 15%+45%f  ジェットナイト率 30%+40%f  リベナント率 8%+22%f  エリート率 2%+8%f

------------------------------------------------------------
アドレナリン(0〜100、表示は 100%〜300%)= バレットタイム
------------------------------------------------------------
  増える: 敵からの被弾 1ダメージにつき +0.3(30ダメージで +9) ※QX_ADREN_HURT
          1キルごとに +20 ※QX_ADREN_KILL
  減る:   敵が近くにいても、最後に被弾してから2秒以上経つと -5/秒 ※QX_ADREN_IDLE / QX_ADREN_GRACE
  減る:   敵がいないと -10/秒 ※QX_ADREN_DECAY。20未満にはならない(スポーン時も20) ※QX_ADREN_MIN
  150%以上で「世界」が遅くなる(host_timescale)
    150% 等速 → 200% x0.8 → 250% x0.7 → 300% x0.5、Quad中は x0.4 ※QX_SLOW_* / QX_QUAD_TIMESCALE
  プレイヤーだけは補正されて、実時間で普通の速さのまま動ける・撃てる
    (速度 x1/s、重力 x1/s^2、sv_accelerate/sv_friction x1/s、アニメ・連射間隔 x s)
  自分の撃った弾も世界の一部なので遅くなる。テレポーター・ジャンプ台の勢いは遅い間は弱め
  シングルプレイのみ(coop/DMでは無効)。死亡・インターミッションで即解除

------------------------------------------------------------
体力の自然回復(旧EXQの仕様を移植)
------------------------------------------------------------
  5秒間 撃たず・ダメージも受けないでいると、HP60まで回復(毎秒5、HP20未満は毎秒10)
  回復が始まる瞬間に息を整える音(gasp)。ライトニングガン装備中は回復しない(体力→セル変換と競合するため)
  ※QX_REGEN_DELAY / QX_REGEN_CAP / QX_REGEN_RATE

------------------------------------------------------------
移動・近接
------------------------------------------------------------
  ジェットパック: 空中でもう一度ジャンプ = 噴射。着地までに3回 ※QX_JET_MAX / QX_JET_UP
    最初は使えない。ジェットナイトが倒れると落とすバックパック(光っている)を拾うと解禁
    一度拾えばマップを越えて持ち越し(parm10)。死亡リスタートではそのレベル開始時の状態に戻る
    すでに持っているときに拾うとロケット+5。落ちたバックパックは120秒で消える
    弾薬は使わない。従来の1番のジェットパック武器は廃止
  自動近接攻撃: 敵との当たり判定の隙間が30未満、かつほぼ正面で自動で斧 ※QX_MELEE_GAP
    発動時に player/taunt.wav を再生(素材は別途用意)
    持っている武器は変わらないが、振っている間は撃てない(無防備)
    連続発動しないよう、振り終わりから0.6秒は再発動しない

------------------------------------------------------------
武器・エイム
------------------------------------------------------------
  オートエイム: スーパーネイルガン / ライトニングガンのみ(独自実装、約18度)
  それ以外: 照準方向のみ。全力移動中が最大拡散、空中はさらに拡散(バレットタイム補正分は除外)

  1 斧 ⇔ ブラスター
      ブラスター: 弾薬不要。エンフォーサーのレーザーと同じ15ダメージ、0.35秒間隔、弾速1000、オートエイムなし
      (見た目は仮でショットガンのモデル)。弾切れ時の持ち替え先も斧→ブラスターに ※QX_BLASTER_*
  ■ 武器バランス(A: DPSの階段 / B: PlayerSkillで全武器が成長)
    A: EXQの「武器Xを持っていると武器Yが強化される」ボーナスはほぼ全廃。各武器の威力は固定
       単体DPS(PlayerSkill 0):ブラスター43 / SG69 / SSG149 / NG110 / SNG160 / GL140+範囲 / RL305 / LG300 / イオン200
    B: プレイヤーが敵に与えるダメージ = x(1 + PlayerSkill/100) ※QX_PLAYER_DMG_SCALE
       敵HPも同じ x(1 + PlayerSkill/100) なので、倒すまでの時間(TTK)はどのPlayerSkillでも同じ
       PlayerSkillが上がって変わるのは「敵の攻撃力・速度・賢さ・エリート率」だけ
       自分の爆風で受ける自爆ダメージは増えない(対象が敵のときだけ倍率がかかる)

  2 ショットガン  シェル1消費(EXQでは無消費だった)。RL所持時のスラッグ弾は廃止
  3 スーパーショットガン  1発13粒x2(EXQは20粒、SNG所持で35粒)、0.7秒固定(LG所持の0.5秒は廃止) ※QX_SSG_PELLETS
  4 ネイルガン   ネイル1消費、オートエイムなし、1発11ダメージ固定 ※QX_NG_DAMAGE、連射 0.1秒
      (SSG/LG所持時の強化ネイルは廃止)
  5 スーパーネイルガン(クラシック復活。EXQのチェーンガンを置き換え)
      1発消費・弾速2000(通常の2倍) ※QX_SNG_SPEED・オートエイム
      威力 12(v0.3で16→12。PlayerSkillによる成長は全武器共通の B に統合) ※QX_SNG_DAMAGE
      連射 0.1秒(2倍速は廃止。QX_SNG_FAST_SKILL を 50 にすると復活)
      PlayerSkill 50超えで追尾ネイル(ゆるめの追尾 0.15、3秒で消滅)
      ※QX_SNG_HOMING_SKILL / QX_SNG_TURN
  6 グレネードランチャー  ロケット1消費、爆風120固定、0.6秒間隔固定
      廃止: NG所持の溶岩弾(空中で途中爆発)、壁に当たると即爆発、NG/LG所持の爆風150/240、RL所持の1.5秒間隔
      残した強化は2つだけ:
      ・RL所持: 爆発時にクラスター6個(EXQは30個)。クラスターは自分には当たらない ※QX_GL_CLUSTERS
      ・LG所持: セル3を追加消費して連鎖電撃。80→60→40→20と1体ごとに減衰、届く距離350
        (EXQは370で1体ごとに-5、距離500) ※QX_GREN_CHAIN / _FALLOFF / _RANGE
        見た目: 弾は旧Lグレネードの青い弾(g_gren.mdl)、銃は v_lg.mdl。セル3未満になると通常のGLの見た目に戻る
      ※マルチグレネード・Lグレネード単体は廃止
  自分の爆風(RL/GL): Quake標準の1/2に加えてさらに x0.5 → 1/4 ※QX_SELF_BLAST
  7 ロケットランチャー  ロケット1消費、直撃120〜140+爆風120、弾速1500(v0.3: EXQのGL所持時の高速弾を全員に)
      ※QX_RL_SPEED / QX_RL_DIRECT。LG所持の追加ロケットは廃止

  鎧の敵(アーマーナイト/ロード/ベイン/スーパーヘルナイト): 弾丸系は1/2(EXQは1/4)、ネイル・スーパーネイルは x2 ※QX_NAIL_PIERCE
    (v0.3: x1.5→x2に戻し、スーパーネイルにも適用。ベインにも適用)
  8 ライトニング → イオン → BFG
      ライトニング: 0.1秒ごとに30固定(EXQはセル40超で60、90超で80+連鎖) ※QX_LG_DAMAGE
      イオン: 1発20 x 4発 / 0.4秒(LG所持ボーナス廃止) ※QX_ION_DAMAGE

------------------------------------------------------------
マップレポート(スコア / テストプレイ記録)
------------------------------------------------------------
  出口に入った瞬間に、そのマップの結果をコンソールに表示(~ で読める)
  インターミッション画面(QuadEXQ エンジン): 標準の「倒した数/総数」の代わりにレポートカード
    SCORE(大きい数字)、時間・撃破数・死亡数、シークレット・PlayerSkill、ボス撃破時刻、
    武器表(構えていた時間 / ダメージ / 撃破 / DPS = ダメージ÷撃っていた時間、外れも含む)。progs がコンソールコマンド qx_statcard で送る
  QuadEXQ エンジンでは quadexq_stats.txt(MODフォルダ内)に追記していく:
    --- マップ開始(何回目の挑戦か、PlayerSkill、体力・アーマー)
    DEATH(時刻、倒した敵、エリートか、PlayerSkillの増減、その時の武器)
    BOSS 撃破(時刻)
    === CLEAR SCORE(時間、死亡数、PlayerSkill 開始→終了、撃破/総数、エリート・スカウト、
        シークレット、ボス撃破時刻、バレットタイム秒数、ジェット回数、与ダメ/被ダメ、
        武器ごとの 構えていた時間・撃っていた時間・命中数・ダメージ・撃破数・DPS)
  数値はそのマップの「今回の挑戦」分。死亡回数だけはエンジンの qx_mapdeaths で restart をまたいで数える
  スコア: 撃破10 / スカウト20 / エリート30 / ボス+300、シークレット100、死亡-200、ノーデス+300
          ※ qx_stats.qc の QX_SC_*

------------------------------------------------------------
マップのボス(クリア条件)
------------------------------------------------------------
  マップ開始2秒後、敵の中から1体をランダムにボスに指名(HP200以上の敵を優先、なければ80以上、なければ全体)
  ボスは必ずエリート + さらにHP x2 ※QX_BOSS_HP。強さは他の敵と同じくPlayerSkillで上がる
  キラキラ光る(EF_BRIGHTFIELD)。見つけると「!!! BOSS !!!」表示。impulse 150 でボスとの距離が見える
  ボスが生きている間は出口(trigger_changelevel)が封印される。倒すと開く
  対象外: smine / 魚 / ウナギ / ゾンビ系(ゴア必須なので)。リベナントにはならない
  クトゥン・シュブニグラスのいるマップや、候補がいないマップでは封印なし
  daikon は v0.3 では出現しない ※QX_DAIKON
  ヴォア(シャルラス)の分裂: 分裂するたびに残りHPを親子で半分ずつ。1体の家系で最大2回まで ※QX_VORE_SPLITS
    (EXQは親のHPそのまま・子150、回数無制限で子も分裂できた)
  スパイクマイン: スーパーウィザードの撃つ追尾マインは撃てば1発で空中爆発(50の爆風)
    マップ配置の monster_smine も HP1300→60 で撃ち落とせる
  QOgre(QuadUTFオーガ)のチェーンソー: HP50以下だと即死(1000)だったのを通常ダメージに
  死亡後のリスタートは最低HP100で開始(QuadEXQエンジン) ※QX_RESTART_HEALTH
  クトゥン/シュブはPlayerSkillのHP倍率の対象外(電撃・テレフラグなど決まった手順で倒すため)
  ボス戦BGM: プレイヤーがボスの500以内に一度入ると track01(music/track01.mp3)に切り替わり、
    ボスを倒すとそのマップ本来の曲に戻る ※QX_BOSS_MUSIC_TRACK / QX_BOSS_MUSIC_RANGE
    切り替わる瞬間に画面中央へ「!!! BOSS !!!」+ボス名、画面フラッシュ

  スカウト(ボスの眷属): ボスと同じ種類の敵が2体、ボスの横にテレポートで一緒に出現(3体の分隊) ※QX_SCOUTS
    待機中はボスについて歩く。ボスが標的を見つけた瞬間、全員が同じ標的を狙う
    左右に分かれて回り込みながら接近。ボスが撃つとスカウトも即座に一斉射撃
    ボスが倒れるとスカウトは暴走(動作速度 x1.3、発光)。スカウトはリベナントにならない
    置ける場所がなければその分は出ない

------------------------------------------------------------
ルーン(v0.5.1〜)
------------------------------------------------------------
  通常の Quake と同じ: ルーンはゲーム中とセーブデータ(serverflags)の中だけ。CONTINUE/ロードで残り、NEW GAME で消える
  (v0.5 の config への保存 qx_runes は廃止)
  QuadEXQ エンジン: ロード時にセーブのルーンをすぐサーバーに反映(通常は次の changelevel まで反映されず、
    ロード後の restart で古いルーンに戻ることがあった)

------------------------------------------------------------
ルーンハンター(v0.6〜) qx_hunter.qc
------------------------------------------------------------
  ルーン2個以上でスタートマップに入ると、4秒後にプレイヤーと同じ姿のライバルが出現して決闘(DM形式、先に10フラグ)
  Quake本来の skill = PlayerSkill/32(0..3、96以上でナイトメア)。マップ読み込み時に決め、死亡後(qx_mapdeaths の変化)に再計算(QX_ExqSkillSync)。EXQ のモンスター差し替え抽選(skillLevel)もこれを使う(旧 QX_BASE_SKILL=1 固定を廃止)。
  ハンターのアイテム回収(QX_HunterItems、QX_AIRun から): 決闘用アイテム(qx_duelitem==1)だけ。48以内のヘルス/アーマーは自動で取る(ヘルスは max まで、メガは max+100 まで、アーマーは上位なら上書き)。体力60%未満かアーマー40未満なら0.5秒ごとに700以内の見えるアイテムを探し、最大3秒走る(体力が減っていればヘルス優先、走りながら25%で撃つ)。K4B は 1300 以内でもロケット30%。
  Blarg のジャンプ攻撃: 1回のジャンプで噛むのは1回だけ(.qx_leaphit)、目標へ向かって飛んでいる時だけ(速度300超かつ向きの内積0.3超)、ダメージ 10+速度/20*random(以前は crandom で負もあり)、次のジャンプまで1.5-2.5秒(.qx_leap_next)。連続ジャンプで押し込まれて死ぬバグの対策。
  Cyberdemon の修正: レール弾(hknightMissile)に think が無く、外れると NULL 関数呼び出しで落ちていた→SUB_Remove。ホーミング弾は0.5秒ごとに追尾、12秒で消える。シャンブラーの差し替え(QUTF/Cyber/Vore)と他の EXQ 差し替えで walkmonster_start が2回呼ばれ total_monsters が二重計上→ .qx_counted で1回だけ数える。
  名前と強さは PlayerSkill/50 で決まる: 0=GuroFighter、1=G か K4B(デュエルごとに50%)、2=Tres(最強)
    服の色(QuadEXQ エンジン qx_colormap_ok): colormap = 32 + 上*14 + 下。GuroFighter 紫(8/8)、G 白(0/0)、K4B 青(13/13)、Tres 赤(4/4)。古いエンジンでは colormap 0 のまま(32以上を送ると古いエンジンは Host_Error になるので必ず cvar を確認)
    G: 260-900 で 50% SNG 8連射(偏差0.7、rh_nail)。Tres: 260-600 で 70% LG 0.6秒(1tick 16 = QX_HUNTER_LG_DAMAGE、0.12秒前の位置を狙う=オートエイムなし、rh_bolt)+ジェットパック(地上で見えていれば0.4秒ごと30%、横跳び380+上430、距離で寄る/離れる、次は2.5-4.5秒後、QX_HunterJet)。K4B: グレネード後の間隔 0.75秒。
    K4B は遠距離でロケットの代わりにグレネード。弾道計算+偏差撃ち(移動先に着弾、誤差±24)。1300超はロケット
    Tres にはオートエイム(SNG/LG)とSNGのホーミングが効かない(QX_AutoAim / QX_NailTarget で除外)
    命中精度・ロケットの偏差撃ち・攻撃間隔・怯みにくさが上がる。動きはエリートAI(円移動・バニホ・回避)
  武器: 近距離SSG(14粒)、それ以外ロケット(弾速1000)。HP 150/200/250 x(1+PlayerSkill/100)、与ダメはDMの素の値
    連射間隔: SSG 1.0/0.85/0.7秒、ロケット 1.3/1.05/0.8秒(エリートの連射2倍は適用しない)
  プレイヤー側: 決闘開始時にアリーナキット(SSG+NG、シェル50・ネイル100)、ハンターを倒すとRL入りバックパック
    決闘中はアドレナリン最低200%(世界0.8倍)、被弾での上昇2倍、フラグで+40%。PlayerSkillの被弾ペナルティなし
    決闘が終わるとキットは回収(決闘前の持ち物に戻る)、残ったRL入りバックパックも消える

------------------------------------------------------------
オートセーブ(QuadEXQエンジン)
------------------------------------------------------------
  チェックポイント: 死ぬと、そのマップのオートセーブ(s19.sav)から再開。無ければ従来どおりマップ最初から
  オートセーブは「安全なとき」だけ: HP50以上 ※QX_SAVE_MIN_HEALTH、着地中、水中・溶岩・スライム外、
    4秒以上被弾なし、バレットタイム外、こちらを狙って見えている敵が1000以内にいない、増援の予告中でない
    危ないタイミングなら安全になるまで待つ(ロード直後に即死するループを防ぐ)
  PlayerSkill はセーブではなく cvar が正: ロードしても死亡ペナルティは戻らない
  マップ開始10秒後と、その後90秒ごと(Mark V 標準の auto_save_0〜2.sav)
  + ボス撃破の1.5秒後(progs がコンソールコマンド autosave を呼ぶ)
  同じ内容をロードメニューの20番スロット(s19.sav)にも書くので、メニューから読める
    sv_autosave_slot 0 で無効、1〜20 で別スロット。sv_autosave 0 でオートセーブ自体を停止
  死亡中・インターミッション中・マルチプレイでは保存しない
